提交视频生成任务，适用于**视频系列模型**（转换模式）。

**接口地址**：`POST /v1/video/generations`

完整参数、首尾帧、参考音频、`asset://` 素材库引用等说明见：

- [Seedance 2.0 转换模式](/zh/docs/api/ai-model/videos/seedance/convert)
- [Seedance 2.0 透传模式](/zh/docs/api/ai-model/videos/seedance/passthrough)
- [素材库 API（用户）](/zh/docs/api/ai-model/videos/material/user)

## 生成模式

| 模式 | 必填参数 | 说明 |
| --- | --- | --- |
| 文生视频 | `model` + `prompt` | 不传 `images`、`metadata.video_urls` |
| 图生视频 | `model` + `prompt` + `images` | `images` 含 1 张图 |
| 首尾帧生视频 | `model` + `prompt` + `first_frame_url` + `last_frame_url` | 也可写在 `metadata`；与多模态参考图互斥 |
| 视频生视频 | `model` + `prompt` + `metadata.video_urls` | 含 1 个视频 |
| 多参考图 | `images` 含多张 | 每张图作为参考素材 |
| 多参考视频 | `metadata.video_urls` 含多个 | 每个视频作为参考素材 |

## images 与 metadata.video_urls 填写规则

- **单张图 / 单个视频**：`images` 或 `metadata.video_urls` 数组只放 1 个 URL
- **多张参考图 / 多个参考视频**：按顺序传入多个 URL，建议在 `prompt` 中说明各素材用途
- **文生视频**：不要传 `images` 或 `metadata.video_urls`
- 地址须为公网可访问的 HTTP/HTTPS，或本平台素材库 `asset://{AssetId}`
- 图片格式：`.png`、`.jpg`、`.jpeg`、`.webp`
- 视频格式：`.mp4`、`.mov`、`.webm`
- 音频格式：`.mp3`、`.wav`（通过 `metadata.audio_urls`）

## 文生视频示例

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "黄昏海岸线，电影级光影，慢镜头推进，海浪拍打礁石",
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
```
