> **请求模式**：转换模式（平台将 `prompt` / `images` / `metadata` 转换为官方 `content[]`）  
> **适用模型**：Seedance 2.0 系列（示例：`Seedance 2.0/uP`）  
> **BaseURL**：`__apiBaseUrl__`  
> **相关文档**：[透传模式](/zh/docs/api/ai-model/videos/seedance/passthrough) · [素材库（用户）](/zh/docs/api/ai-model/videos/material/user) · [素材库（中转站）](/zh/docs/api/ai-model/videos/material/relay)

## 1. 接口概览

| 项目   | 说明                                                      |
| ---- | ------------------------------------------------------- |
| 提交任务 | `POST /v1/video/generations`                            |
| 查询任务 | `GET /v1/video/generations/{task_id}`                   |
| 提交地址 | `__apiBaseUrl__/v1/video/generations`           |
| 查询地址 | `__apiBaseUrl__/v1/video/generations/{task_id}` |
| 鉴权   | `Authorization: Bearer <YOUR_API_KEY>`                  |
| 内容类型 | `Content-Type: application/json`                        |
| 示例模型 | `Seedance 2.0/uP`                                       |

## 2. 请求头

```http
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json
```

## 3. 请求参数

### 3.1 基础参数

| 参数名             | 类型       | 必填   | 说明                                                              |
| --------------- | -------- | ---- | --------------------------------------------------------------- |
| model           | string   | 是    | 模型名称，如 `Seedance 2.0/uP`；平台自动映射为上游真实模型 ID                          |
| prompt          | string   | 条件必填 | 正向提示词；文生视频必填。平台会将其封装为官方 `content[]` 中的第一个 `text` 对象             |
| duration        | integer  | 否    | 视频时长（秒）。支持 `4`–`15`，以及 `-1`（由模型智能选择时长）。也可写在 `metadata.duration` |
| images          | string[] | 条件必填 | 图片地址数组；图生视频、多参考图使用                                              |
| first_frame_url | string   | 否    | 首帧图地址                                                           |
| last_frame_url  | string   | 否    | 尾帧图地址                                                           |
| metadata        | object   | 否    | 扩展参数（媒体、规格、控制类），见下文                                             |

### 3.2 媒体参数

| 参数名                                        | 类型       | 必填   | 说明                                           |
| ------------------------------------------ | -------- | ---- | -------------------------------------------- |
| images                                     | string[] | 条件必填 | 图片地址数组。支持公网 URL 或素材库 `asset://`              |
| first_frame_url / metadata.first_frame_url | string   | 否    | 首帧图地址（顶层优先）。支持公网 URL 或 `asset://`            |
| last_frame_url / metadata.last_frame_url   | string   | 否    | 尾帧图地址（顶层优先）。支持公网 URL 或 `asset://`            |
| metadata.video_urls                        | string[] | 条件必填 | 参考视频地址数组；视频生视频、多参考视频使用。支持公网 URL 或 `asset://` |
| metadata.video_url                         | string   | 否    | 单个参考视频地址（与 `video_urls` 等价的简写）               |
| metadata.audio_urls                        | string[] | 否    | 参考音频地址数组；口型/配音参考。支持公网 URL 或 `asset://`       |
| metadata.audio_url                         | string   | 否    | 单个参考音频地址（与 `audio_urls` 等价的简写）               |
| metadata.generate_audio                    | boolean  | 否    | 是否生成成片音频；**默认 `true`**。传 `false` 则输出无声视频     |

### 3.3 视频规格参数

以下字段可通过**顶层**或 **`metadata`** 传入（推荐写法见示例；顶层 `resolution` / `ratio` 会自动落到 `metadata`）：

| 参数名 | 类型 | 必填 | 可选值 / 默认 | 说明 |
| --- | --- | --- | --- | --- |
| resolution / metadata.resolution | string | 否 | `480p`、`720p`、`1080p`、`4k` | 分辨率；也可通过 `size`（如 `1280x720`）由平台自动换算 |
| ratio / metadata.ratio | string | 否 | `16:9`、`9:16`、`1:1` 等 | 画面比例；也可通过 `size` 自动换算 |
| duration / metadata.duration | integer | 否 | `4`–`15`，或 `-1` | 时长（秒）；`-1` 表示模型智能选择 |
| metadata.seed | integer | 否 | 任意整数 | 随机种子，便于复现结果 |
| metadata.watermark | boolean | 否 | `true` / `false` | 是否加水印 |

### 3.4 生成控制参数

| 参数名                              | 类型       | 必填  | 传入位置                             | 说明                                       |
| -------------------------------- | -------- | --- | -------------------------------- | ---------------------------------------- |
| callback_url                     | string   | 否   | 顶层或 `metadata.callback_url`      | 任务完成回调地址                                 |
| return_last_frame                | boolean  | 否   | 顶层或 `metadata.return_last_frame` | 是否返回尾帧图；为 `true` 时查询结果含 `last_frame_url` |
| metadata.service_tier            | string   | 否   | 仅 `metadata`                     | 服务等级（按上游约定填写）                            |
| metadata.execution_expires_after | integer  | 否   | 仅 `metadata`                     | 任务执行过期时间（秒，按上游约定）                        |
| metadata.generate_audio          | boolean  | 否   | 仅 `metadata`                     | 是否生成成片音频；默认 `true`                       |
| metadata.tools                   | object[] | 否   | 仅 `metadata`                     | 工具列表，如 `[{"type":"web_search"}]`         |

### 3.5 转换模式不支持 / 受限项

| 官方能力                                 | 转换模式状态                                           | 建议                 |
| ------------------------------------ | ------------------------------------------------ | ------------------ |
| `safety_identifier`                  | ❌ 不支持                                            | 使用透传模式             |
| `priority`                           | ⚠️ 转换模式不主动设置                                     | 透传模式可原样转发          |

### 3.6 metadata 字段一览

| 字段                      | 类型       | 说明                   | 示例                                                |
| ----------------------- | -------- | -------------------- | ------------------------------------------------- |
| video_urls              | string[] | 参考视频列表（视频类场景必填）      | `["https://.../a.mp4"]` 或 `["asset://asset-xxx"]` |
| video_url               | string   | 单个参考视频（简写）           | `"https://.../a.mp4"`                             |
| audio_urls              | string[] | 参考音频列表               | `["https://.../ref.mp3"]`                         |
| audio_url               | string   | 单个参考音频（简写）           | `"https://.../ref.wav"`                           |
| generate_audio          | boolean  | 是否生成成片音频；未传默认 `true` | `true` / `false`                                  |
| resolution              | string   | 分辨率                  | `480p`、`720p`、`1080p`、`4k`                        |
| ratio                   | string   | 画面比例                 | `16:9`、`9:16`、`1:1`                               |
| duration                | integer  | 时长（秒）                | `5`、`-1`                                          |
| seed                    | integer  | 随机种子                 | `20260617`                                        |
| watermark               | boolean  | 是否加水印                | `false`                                           |
| callback_url            | string   | 回调地址                 | `"https://example.com/hook"`                      |
| first_frame_url         | string   | 首帧图地址（也可顶层传入）        | `"https://.../start.png"`                         |
| last_frame_url          | string   | 尾帧图地址（也可顶层传入）        | `"https://.../end.png"`                           |
| return_last_frame       | boolean  | 是否返回尾帧图              | `true`                                            |
| service_tier            | string   | 服务等级                 | 按上游约定                                             |
| execution_expires_after | integer  | 执行过期时间（秒）            | `3600`                                            |
| tools                   | object[] | 工具列表                 | `[{"type":"web_search"}]`                         |

### 3.7 生成模式对照

| 模式     | 必填参数                                                      | 说明                                                         |
| ------ | --------------------------------------------------------- | ---------------------------------------------------------- |
| 文生视频   | `model` + `prompt`                                        | 不传 `images`、`metadata.video_urls`                          |
| 图生视频   | `model` + `prompt` + `images`                             | `images` 含 1 张图（`reference_image`）                         |
| 首尾帧生视频 | `model` + `prompt` + `first_frame_url` + `last_frame_url` | 也可写在 `metadata`                                            |
| 视频生视频  | `model` + `prompt` + `metadata.video_urls`                | 含 1 个视频                                                    |
| 多参考图   | `images` 含多张                                              | 每张图作为参考素材（均为 `reference_image`）                            |
| 多参考视频  | `metadata.video_urls` 含多个                                 | 每个视频作为参考素材                                                 |
| 参考音频   | `metadata.audio_urls`（或 `audio_url`）                      | 可与图/视频参考组合；用于口型、配音节奏等                                      |
| 无声视频   | `metadata.generate_audio=false`                           | 关闭成片音频生成                                                   |
| 返回尾帧   | `return_last_frame=true`（顶层或 metadata）                    | 查询结果含 `content.last_frame_url` / `metadata.last_frame_url` |

## 4. images / video_urls / audio_urls 填写规则

### 4.1 单张图 / 单个视频 / 单个音频

`images` 数组只放 1 个地址：

```json
"images": [
  "https://cdn.example.com/main.png"
]
```

`metadata.video_urls` 数组只放 1 个地址：

```json
"metadata": {
  "video_urls": [
    "https://cdn.example.com/source.mp4"
  ]
}
```

`metadata.audio_urls` 数组只放 1 个地址（也可用 `audio_url` 简写）：

```json
"metadata": {
  "audio_urls": [
    "https://cdn.example.com/voice.mp3"
  ]
}
```

### 4.2 多张参考图 / 多个参考视频 / 多个参考音频

多参考图——顶层 `images` 按顺序传入：

```json
"images": [
  "https://cdn.example.com/角色面部.png",
  "https://cdn.example.com/服装参考.png",
  "https://cdn.example.com/画风参考.png"
]
```

多参考视频——`metadata.video_urls` 按顺序传入：

```json
"metadata": {
  "video_urls": [
    "https://cdn.example.com/主素材.mp4",
    "https://cdn.example.com/运镜参考.mp4",
    "https://cdn.example.com/氛围参考.mp4"
  ]
}
```

多参考音频——`metadata.audio_urls` 按顺序传入：

```json
"metadata": {
  "audio_urls": [
    "https://cdn.example.com/旁白.mp3",
    "https://cdn.example.com/环境音.wav"
  ]
}
```

### 4.3 参数语义

| 参数                                   | 单值                             | 多值                     |
| ------------------------------------ | ------------------------------ | ---------------------- |
| `images`                             | 数组 1 张，图生视频（`reference_image`） | 数组多张，均为参考图             |
| `first_frame_url` / `last_frame_url` | 各传 1 个地址，首尾帧生视频                | 不支持数组；中间参考图仍放 `images` |
| `metadata.video_urls`                | 数组 1 个，视频生视频                   | 数组多个，均为参考视频            |
| `metadata.audio_urls`                | 数组 1 个，单参考音频                   | 数组多个，均为参考音频            |
| `metadata.generate_audio`            | `true`（默认）生成音频                 | `false` 输出无声视频         |

### 4.4 注意事项

- 地址须为公网可访问的 HTTP/HTTPS URL，或本平台素材库的 `asset://{AssetId}`（见第 13 节）。
- 图片格式：`.png`、`.jpg`、`.jpeg`、`.webp`。
- 视频格式：`.mp4`、`.mov`、`.webm`。
- 音频格式：`.mp3`、`.wav`。
- 多参考时建议在 `prompt` 中说明各素材用途。
- 文生视频不要传 `images` 或 `metadata.video_urls`；参考音频为可选增强项。
- `generate_audio` 未传时默认 `true`；仅在需要无声成片时显式传 `false`。
- 首尾帧请用 `first_frame_url` / `last_frame_url`，不要依赖 `images` 顺序推断角色。

## 5. 文生视频

不传 `images` 和 `metadata.video_urls`。

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "黄昏海岸线，电影级光影，慢镜头推进，海浪拍打礁石",
    "duration": 5,
    "resolution": "720p",
    "ratio": "16:9",
    "metadata": {
      "generate_audio": true,
      "watermark": false,
      "return_last_frame": true
    }
  }'
```

**提交成功返回示例：**

```json
{
  "id": "task_abc123",
  "object": "video.generation",
  "model": "Seedance 2.0/uP",
  "status": "queued",
  "progress": 0,
  "created_at": 1784716366
}
```

`images` 传 1 张主图。

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "人物缓慢转头，背景树叶随风飘动",
    "images": [
      "https://cdn.example.com/主角正面照.png"
    ],
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```

### 6.1 首尾帧生视频

使用通用字段 `first_frame_url` / `last_frame_url`（顶层或 `metadata` 均可）。首尾帧模式 和 多模态参考图模式 互斥，不能在同一次请求里一起使用。

**推荐写法（顶层）：**

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "镜头从首帧平滑过渡到尾帧，人物自然转身",
    "first_frame_url": "https://cdn.example.com/start.png",
    "last_frame_url": "https://cdn.example.com/end.png",
    "duration": 5,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "generate_audio": true
    }
  }'
```

**等价写法（metadata）：**

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "镜头从首帧平滑过渡到尾帧，人物自然转身",
    "duration": 5,
    "metadata": {
      "first_frame_url": "https://cdn.example.com/start.png",
      "last_frame_url": "https://cdn.example.com/end.png",
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```

## 10. 参考音频、成片音频与控制参数

```bash
      ],
      "generate_audio": true,
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```

### 10.2 关闭成片音频（无声视频）

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
```

### 10.3 回调 + 返回尾帧 + 联网搜索

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "根据最新天气资讯生成海边延时摄影风格短片",
    "duration": 5,
    "callback_url": "https://example.com/hooks/seedance",
    "return_last_frame": true,
    "metadata": {
      "resolution": "720p",
      "ratio": "16:9",
      "tools": [{"type": "web_search"}],
      "seed": 20260722,
      "watermark": false
    }
  }'
```

| 字段 | 说明 |
| --- | --- |
| `metadata.audio_urls` / `audio_url` | 参考音频输入，影响口型、节奏等；**不等于**成片是否有声 |
| `metadata.generate_audio` | 控制成片是否生成音频；默认 `true` |
| `callback_url` / `return_last_frame` | 支持顶层或 `metadata` 二选一传入 |

| status | string | 任务状态，见下表 |
| progress | integer | 进度百分比，`0`–`100` |
| created_at | integer | 创建时间（Unix 秒） |
| completed_at | integer | 完成时间（Unix 秒）；未完成时可能不返回 |
| error | object \| null | 失败时的错误信息；成功为 `null` |
| ratio | string | 实际上游生成的画面比例（如 `16:9`） |
| resolution | string | 实际上游生成的分辨率（如 `480p`） |
| duration | integer | 实际上游生成的时长（秒） |
| output.video_url | string | 成片视频地址（平台统一输出字段） |
| content.video_url | string | 成片视频地址（上游 content 透传，通常与 `output.video_url` 一致） |
| content.last_frame_url | string | 尾帧图地址；需提交时 `return_last_frame=true` 才有 |
| metadata.last_frame_url | string | 尾帧图地址的 metadata 副本（可能与 `content.last_frame_url` 相同） |
| usage.completion_tokens | integer | 上游 completion token 用量 |
| usage.total_tokens | integer | 上游 total token 用量 |

> **字段关系**：`output.video_url` 与 `content.video_url` 通常指向同一成片；业务侧任取其一即可。`last_frame_url` 可能同时出现在 `content` 与 `metadata`，内容一般相同。

### 11.3 status 枚举

| status | 含义 |
| --- | --- |
| queued | 排队中 |
| in_progress | 生成中 |
| completed | 成功 |
| failed | 失败 |

## 12. 错误处理

| 场景 | 处理建议 |
| --- | --- |
| 图生视频未传 `images` | 在 `images` 中补充至少 1 张图片 URL 或 `asset://` |
| 视频生视频未传 `metadata.video_urls` | 在 `metadata.video_urls` 中补充至少 1 个视频地址 |
| 资源 URL 无法访问 | 确认公网可达、格式正确；或改用素材库 `asset://` 引用 |
| 素材库引用失败 | 确认素材 `Status=Active`，且 `asset://` 属于当前账号 |
| 鉴权失败 | 检查 API Key |
| 生成失败 | 简化 `prompt` 或减少参考素材数量 |
| 需要首帧/尾帧精确控制 | 改用透传模式，并设置图片 `role` |
| 需要 `safety_identifier` | 转换模式不支持，请开启透传后使用透传文档写法 |

## 13. 素材库素材怎么用

视频生成的 `images`、`metadata.video_urls`、`metadata.audio_urls` 除了传公网 URL，还可以引用本平台**素材库**中已就绪的素材。

### 13.1 引用格式

```
asset://{AssetId}
```

示例：`asset://asset-20260612200812-mmq8g`

上传/查询素材接口会返回：

| 字段 | 说明 |
| --- | --- |
| `asset_id` / `Id` | 素材 ID，如 `asset-xxx` |
| `asset_uri` | 可直接复制使用的引用地址，格式为 `asset://asset-xxx` |
| `status` / `Status` | 须为 `Active` 后方可在视频生成中引用 |

### 13.2 使用前准备（二选一）

**方式 A：素材库 Action API**

```
1. CreateAssetGroup / 真人认证流程 → 获得 GroupId
2. CreateAsset（公网 URL）       → 获得 AssetId
3. GetAsset 轮询至 Status=Active
4. 视频生成时使用 asset://{AssetId}
```

**方式 B：个人素材 API**

```
1. POST /api/material/personal/upload
   或 POST /api/material/personal/upload-url
2. 取返回的 asset_uri（或自行拼接 asset:// + asset_id）
3. 确认 status=Active 后用于视频生成
```

### 13.3 在视频生成中替换地址

把原来的公网 URL **原样替换**为 `asset_uri` 即可，参数位置不变：

| 素材类型 | 放入的字段 |
| --- | --- |
| 图片（参考图） | `images` |
| 图片（首/尾帧） | `first_frame_url` / `last_frame_url`（或 `metadata` 同名字段） |
| 视频 | `metadata.video_urls` |
| 音频 | `metadata.audio_urls` |

### 13.4 完整示例：素材库图 + 参考音频

```bash
curl -X POST "__apiBaseUrl__/v1/video/generations" \
  -H "Authorization: Bearer <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Seedance 2.0/uP",
    "prompt": "保持素材库角色面部特征，根据参考音频说话",
    "images": [
      "asset://asset-20260612200812-mmq8g"
    ],
    "duration": 5,
    "metadata": {
      "audio_urls": [
        "asset://asset-20260617155448-fkgww"
      ],
      "generate_audio": true,
      "resolution": "720p",
      "ratio": "16:9"
    }
  }'
```

### 13.5 素材库引用注意

1. **先就绪再引用**：`Pending` 状态不可用，请先轮询至 `Active`。
2. **账号隔离**：只能引用当前 API Key 所属账号下的素材。
3. **类型对应**：图片素材放 `images`，视频放 `video_urls`，音频放 `audio_urls`，不要混放。
4. **与公网 URL 可混用**：同一请求中可以一部分用 `https://...`，一部分用 `asset://...`。
5. **完整素材管理接口**：分组、上传、删除、真人认证等请查阅 [素材库 API（中转站接入）](/zh/docs/api/ai-model/videos/material/relay)；个人素材快捷上传请查阅 [素材库 API（用户）](/zh/docs/api/ai-model/videos/material/user)。
